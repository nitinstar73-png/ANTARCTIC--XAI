ANTARCTIC-XAI — Cinematic Prototype
====================================

This is a standalone HTML prototype built around the reference images supplied by the user.

FEATURES
- Antarctica / End of the Earth cinematic opening screen
- Click/touch Earth to enter the satellite command center
- Animated satellite with scanning/telemetry effect
- Antarctic satellite-view panel
- Ship voyage simulation with iceberg collision warning and navigation hold
- Glacier-style bar statistics and sea-ice extent line chart
- Explicit Machine Learning section (XGBoost risk model + trajectory prediction)
- SHAP-style XAI explanation section
- Antarctic risk map with risk zone and recommended route
- Responsive desktop/mobile layout

RUN
1. Open index.html directly in a browser, or use VS Code Live Server.
2. No build step is required for this prototype.

IMPORTANT
The numbers and charts in this visual prototype are UI/demo values. For the real project, connect the ML backend and verified satellite/ocean/weather datasets so the displayed values are computed from actual data.
